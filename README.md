# 圖書館密令：失落的知識鑰匙

115 學年度楊梅高中圖書館新生利用教育互動解謎遊戲。以使用者提供的 1F、2F 配置圖與新生利用教育 PDF 為教材基礎。

## 特色

- 原始館內 1F、2F 平面圖作為場景，搭配教學用節點路網（**非實際無障礙路徑或避難動線**）。
- 18 關線性連鎖挑戰，必須逐點移動、走到樓梯換層、抵達指定區域才能作答。
- 單選、複選、數字運算與排序，錯誤扣分、提示扣分、獎勵物品、背包、任務解鎖。
- 鍵盤方向鍵、WASD、滑鼠與手機觸控操作。
- 任務進度儲存於 `localStorage`；可匯出 JSON 學習紀錄。
- 純靜態 HTML/CSS/JS，不使用 CDN，響應式設計（RWD）與 PWA 離線快取。

## 使用

1. 將整個資料夾（包含 assets）上傳 GitHub Repository，並啟用 Settings → Pages。
2. GitHub Pages 網址開啟 `index.html` 即可遊玩，透過瀏覽器安裝選單可安裝 PWA。
3. 本機預覽亦可用 `python -m http.server 8000` 後開啟 `http://localhost:8000/`。
4. 若直接雙擊 `index.html` 以 `file://` 開啟，多數一般互動仍可用，但 PWA Service Worker 無法啟用。

## 遊戲控制

- 每次只能前往與角色目前節點相鄰的節點。虛線僅代表遊戲通路。
- 遇到樓梯節點時，按「使用樓梯」才能換樓層。
- 「自動規劃路線」顯示目前樓層到任務點的最短節點路徑，但不會自動替玩家移動。
- 任務需先抵達指定節點。答錯扣 15 分、提示扣 5 分。
- 透過「匯出紀錄」可下載 JSON，包含答錯、提示、耗時、任務進度等資訊。

## 教學使用提醒

- 依教材：08:00–16:00 開放，第 8 堂館務處理；借書最多 4 本、2 週，續借於到期前 1–2 日辦理、續借 2 週；學生不得在館內任意使用手機、奔跑、喧嘩、攜帶飲食與書包。
- **建議在教室使用投影或核准設備遊玩**，不要把虛擬複雜操作轉為要求學生在館內奔跑或違規使用手機。
- 配置圖只畫出區域。小型節點位置與連接由遊戲設計者根據配置圖建立，非精密座標，部分任務物件為情境假設，不表示該物品一定放置於該書架。
- 學習紀錄只存在使用裝置的瀏覽器，不包含教師帳號、學生身分管理或雲端成績收集。重設瀏覽器可能清除進度，建議課後匯出檔案。
- 本版不是 3D 引擎，不含實際 3D 建模或自由漫遊；屬於以館內平面圖為主的 2D 遊戲原型。
